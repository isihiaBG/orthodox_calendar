# Страницата на приложението

⚠ Тази папка се публикува през **GitHub Pages** (клон `main`, папка `/docs`).

## Какво има тук и защо

- **`.well-known/assetlinks.json`** — файлът, с който домейнът потвърждава, че
  приложението `isihiabg.orthodox_calendar` има право да отваря неговите
  линкове (Android App Links). Съдържа package name-а и SHA-256 отпечатъка на
  подписващия ключ.

  ⚠ **Сменѝ ли се едно от двете, файлът трябва да се обнови** — иначе Android
  спира да отваря линковете в приложението и ги праща в браузъра. Тъкмо затова
  и двете бяха закотвени преди тази стъпка (виж CLAUDE.md).

  ⚠ Отпечатъкът се вади с `apksigner`, НЕ с `keytool`:

      ~/android/build-tools/37.0.0/apksigner verify --print-certs <apk>

  и се преобразува в главни букви с двоеточия през два знака.

- **`.nojekyll`** — ⚠ ЗАДЪЛЖИТЕЛЕН. Без него GitHub Pages минава съдържанието
  през Jekyll, а той **пропуска всяка папка, започваща с точка** — тоест точно
  `.well-known/`. Файлът щеше да върне 404 и проверката на Android да се
  проваля мълчаливо.
