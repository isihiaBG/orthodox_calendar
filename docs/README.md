# Страницата на приложението

⚠ Публикува се през **GitHub Pages** (клон `main`, папка `/docs`) на адрес
https://isihiabg.github.io/orthodox_calendar/

- **`404.html`** — страницата за споделен цитат. Поема
  `/orthodox_calendar/q/<кодирано>` и показва цитата на човек БЕЗ приложението.

  ⚠ Не `q/index.html`: GitHub Pages е статичен, а низчето е различно за всеки
  цитат. 404.html е обичайният похват за такива адреси.

  ⚠ **Open Graph визитка в чата НЯМА как да се направи оттук** — чатовете
  четат мета-таговете без да изпълняват JavaScript, а те трябва да са
  различни за всеки цитат. Иска истински сървър.

⚠ Файлът `assetlinks.json` НЕ е тук, а в отделното хранилище
`isihiaBG/isihiaBG.github.io`: Android го чете само от КОРЕНА на домейна.
Оттам важи за целия хост, включително за тези адреси.
