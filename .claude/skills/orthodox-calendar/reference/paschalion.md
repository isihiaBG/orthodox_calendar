# Пасхалия, стилове, църковна година

## Пасха

Александрийската пасхалия, смятана по юлианския календар, после превърната
в гражданска дата:

```
a = y % 4;  b = y % 7;  c = y % 19
d = (19c + 15) % 30
e = (2a + 4b − d + 34) % 7
месец = (d + e + 114) // 31          (юлиански)
ден   = (d + e + 114) % 31 + 1
```

Юлианската дата → гражданска **през юлианския ден (JDN)**, не с твърдо „+13“:
разликата е 13 дни за 1900–2099 и става 14 от 1.III.2100. Кратката формула
за разликата е `c − c//4 − 2`, където `c = година // 100`.

⚠ **Пасхата е една и съща гражданска дата и по стар, и по нов стил.**
БПЦ (новоюлиански календар от 1968 г.) пази юлианската пасхалия.

Проверки: 2025 → 20.IV, 2026 → 12.IV, 2027 → 2.V.

## Стар и нов стил

| | неподвижен празник ММ-ДД | Пасха и подвижното |
|---|---|---|
| нов стил | гражданска дата = ММ-ДД | обща |
| стар стил | гражданска = ММ-ДД + 13 дни | обща |

Затова:
- Рождество Христово (12-25) по стар стил е **7 януари** — на следващата
  гражданска година. Всяко търсене „кога пада празникът“ проверява годините
  y−1, y, y+1.
- Петровият пост (от Пасха+57 до Петровден 06-29) е по-дълъг по стар стил
  (Петровден е 12.VII граждански) и може да липсва изцяло при късна Пасха
  по нов стил.
- Един физически ден носи различни памети в двата стила. **Не превеждай
  четива и памети с отместване** — генерирай за всеки стил поотделно от
  църковните дати.

## Църковната година и „управляващата“ Пасха

Броенето „N-та седмица/неделя след Петдесетница“ продължава от **миналогодишната**
Пасха до деня преди Неделята на Митаря и Фарисея (Пасха − 70) на следващата.
Оттам започва Триодът на новата.

```python
def governing_pascha(date):
    p = pascha(date.year)
    return p if date >= p - 70 дни else pascha(date.year - 1)
```

Гражданските граници на една църковна година в базата: 1.I – 31.XII
църковно, тоест по стар стил 14.I – 13.I следващата година.

## Обратното — църковната дата на граждански ден

По нов стил тя е самата гражданска дата. По стар стил — гражданската минус
разликата (13 дни за 1900–2099). Нужна е, за да се намерят паметите и
неподвижните четива на деня.
