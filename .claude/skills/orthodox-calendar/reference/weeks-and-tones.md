# Седмици, недели, гласове

## Имената на седмиците и неделите

Всичко се смята от **отместването от управляващата Пасха** (paschalion.md).

- **Триод** (−70…−1): Митар и Фарисей, Блудния син, Месопустна, Сиропустна,
  после „Седмица/Неделя N на Великия пост“ (N = 1…6), Страстна седмица.
  Подготвителните седмици започват в понеделник −69, −62, −55.
- **Пентикостар** (0…49): Светла седмица, „Неделя N след Пасха“ (2 —
  Томина, 3 — Мироносици, 4 — Разслабления, 5 — Самарянката, 6 — Слепия,
  7 — отците на I събор), Петдесетница.
- **След Петдесетница**: „Неделя N след Петдесетница“ с
  `N = (отм − 49) // 7` — неделята на Всички светии (+56) е N = 1. Делниците:
  „Седмица N след Петдесетница“, започва веднага след Петдесетница.
  Добавки: N=1 „на всички светии“, N=2 „на всички български светии…“,
  N=8 „на св. отци от Шестте вселенски събора“ (когато се пада там).

Всички истински начала на седмица в този прост диапазон са понеделници
≡ 1 (mod 7) спрямо Пасха.

### Котвената опашка (есен–зима)

Отгоре на „Неделя N след Петдесетница“ се добавя:

| неделя | надпис |
|---|---|
| точно преди Въздвижение | † Неделя преди Въздвижение |
| точно след Въздвижение | † Неделя след Въздвижение |
| между тях и Праотците | † Неделя k след Нед. подир Въздвижение (k = 1, 2, …) |
| две седмици преди Рождество | † Неделя на св. Праотци Христови |
| точно преди Рождество | † Неделя преди Рождество Христово, на св. отци |
| точно след Рождество | † Неделя след Рождество Христово |
| преди / след Богоявление | Неделя преди / след Богоявление — **замества** целия надпис |

⚠ Падне ли празникът в неделя, самият ден не получава „преди/след“;
съседните са седмица встрани.

## Гласът (осмогласие)

**Скритият глас** е непрекъснат седмичен кръг 1…8…1:
- сменя се **в неделя** — седмицата Нед–Съб носи гласа на своята неделя;
- **рестартира на 1** на две места в пасхалния цикъл: **Томина неделя**
  (Пасха+7) и **Неделята на Митаря** (Пасха−70) — второто е потвърдено от
  данните: непрекъснато броене само от Антипасха дава грешно;
- **Светлата седмица** е свой дневен ред: Пасха…Светла събота =
  `0, 2, 3, 4, 5, 6, 8` (Пасха без глас).

```python
sunday_off = off − (iso_weekday % 7)          # неделята на седмицата
anchor = 7 if sunday_off >= 7 else −70
глас = (sunday_off − anchor) // 7 % 8 + 1
```

**Показваният глас е 0** (без глас), когато денят е:
- в Страстната седмица (−6…−1) или Цветница (−7);
- Господски празник: Богоявление, Благовещение, Преображение, Въздвижение,
  Рождество Христово, Пасха, Възнесение, Петдесетница;
- неделята преди или след Богоявление.

⚠ Богородичните празници и Обрезание **не** гасят гласа. Седмицата/неделята
в базата пази СКРИТИЯ глас, дори когато денят показва 0.

Проверено със `scripts/church_calendar.py` срещу генератора: всеки ден
2025–2030, двата стила — нула разминавания.
