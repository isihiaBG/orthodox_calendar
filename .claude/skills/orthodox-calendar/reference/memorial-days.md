# Задушници и родителски съботи

По българската практика:

| ден | правило |
|---|---|
| Месопустна задушница | Пасха − 57 (съботата преди Месопустна неделя) |
| Родителска събота, 2-ра седмица на поста | Пасха − 36 |
| Родителска събота, 3-та седмица | Пасха − 29 |
| Родителска събота, 4-та седмица | Пасха − 22 |
| Петдесетнична (Троицка) задушница | Пасха + 48 (съботата преди Петдесетница) |
| Архангелова задушница | съботата **строго преди** Архангеловден (църковна 11-08), в стила |

⚠ У нас няма Димитриевска събота (руската практика) — вместо нея е
Архангеловата задушница. Списъкът е по българската практика; потребителят
може да го уточни.

⚠ Архангеловата е закотвена към НЕПОДВИЖЕН празник → по стар стил пада
около 21.XI граждански, по нов — около 8.XI. Смята се от гражданската дата
на празника в стила, не с отместване.

Словата/поученията за задушниците се адресират със същия литургичен адрес
(Месопустната = `T2:6`, виж readings.md) — ⚠ НЕ `T3:6`, което е Сирната
събота.
