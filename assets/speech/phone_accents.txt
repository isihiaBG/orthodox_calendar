# ударената гласна е ГЛАВНА („кОмнин"). Само за думите, които той чете
# криво: другите ги чете добре и сам (над 90%).
#
# ⚠ Отделно от tools/tts/accents.txt (ElevenLabs) — двата гласа бъркат
# различни неща. Изворът е ТОЗИ файл; попълва се от поправките, събрани в
# тестовия режим (Настройки → „Тестов режим" → „Копирай поправките").
# Решава авторът.
#
# Начинът (по желание, след интервал): „латинска" (о/у → ó/ú), „двойна"
# (удвоена гласна) или „тире" („Ком-нин"); без него — латинска за о/у,
# иначе двойна. Пример: „кОмнин тире". (lib/test_mode.dart, PhoneStress)
#
# ⚠ При „тире" главната буква е по-скоро МЯСТОТО НА ТИРЕТО, избрано на слух
# (тирето пада в края на сричката ѝ), а не непременно истинското ударение —
# напр. „Устроил тире" → „ус-троил". Не ползвай този файл като речник на
# ударенията за друго. При ударена последна сричка тирето няма къде и думата
# остава както е.
#
# Свой изговор (начин „свой"): „думата = както да прозвучи", напр.
# „комнин = ко мнин" — вдясно дословно, до края на реда.
#
# Кога важи (по желание, след „ | "): „главна" / „малка" — само ако думата в
# текста е с главна / малка буква („госпОда тире | главна" — Го́спода, Бог;
# „господА двойна | малка" — господа́); „преди: пред", „след: бога" — само в
# този израз. По-тясното правило печели (изразът пред буквата, буквата пред
# „всякак").
