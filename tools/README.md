# tools/ — конвейерите на проекта

Тук живее всичко, с което се **произвеждат** базите и книгите в `assets/`.
Приложението само ги чете; нито един от тези скриптове не се пуска на
устройството.

⚠ **Започни оттук, ако поемаш проекта.** Всяка папка има свой `README.md` с
пълния ред на пускане, аргументите и предупрежденията. Този файл е само
указател.

### Самостоятелни скриптове в тази папка

**`build_lives_index.py`** — прави `assets/lives_index.json`: указателят
номер → (том, адрес, заглавие) за всичките 1155 жития в томовете. Без него
кръстосаните препратки между житията не се отварят.
```bash
python3 tools/build_lives_index.py
```
⚠ Маха номерата на бележките под линия от заглавията **като ЕЛЕМЕНТ**, не с
регекс по цифри: заглавията носят и истински числа („светите 42 мъченици“).

**`extract_covers.py`** — изважда кориците от `.epub` томовете в
`assets/covers/` за библиотеката с Cover Flow.
```bash
python3 tools/extract_covers.py
```
⚠ Папката `assets/covers/` е производна и е в `.gitignore` — този скрипт я
пресъздава. ⚠⚠ Но `assets/bible_covers/` **не е производна** (рисувана е на
ръка) — нея никой скрипт не може да върне.

## ⚠ Общи правила, които важат за ВСИЧКИ конвейери

1. ⚠⚠ **Поправките се нанасят в ИЗВОРА, не в изделието.** Поправка направо в
   база или в .epub се губи при следващото сглобяване.
2. ⚠⚠ **Платените стъпки са тези с `deepseek` в името.** Винаги първо с
   `--limit 3`, за да се види качеството и цената.
3. ⚠⚠ **Ключът е в `.env` и НИКОГА в скрипт.** `**/.env` е заключен в
   `.gitignore`; хранилището е публично.
4. ⚠⚠ **Пълният ред не се съкращава.** Няколко конвейера имат стъпки след
   основната (песнопения, надписи, картинки); пропуснати, вършената работа
   изчезва **без никакъв признак**.
5. ⚠⚠ **Резервно копие преди пипане на база.** Базите в `assets/db/` **не са
   в git** — само собственото ти копие може да те върне назад.
6. ⚠ **Никакви `.bak-…` в `assets/` преди билд.** `pubspec.yaml` включва
   цялата папка; веднъж така в APK-то заминаха 15,8 MB копия.
   ```bash
   ls assets/db/*.bak-*      # трябва да е празно
   ```
7. ⚠ **В git влизат САМО `scripts/` и `README.md`.** Данните (`input/`,
   `output/`, `work/`, `cache/`) остават извън — тежки, производни и с чужди
   права.
