# tools/lives_plus/ — словата и поученията на свт. Димитрий Ростовски

⚠⚠ ПАПКАТА Е В `.gitignore`. Този файл е ЕДИНСТВЕНИЯТ запис на находките —
изтрие ли се, знанието си отива с нея.

Три .epub книги в `input/` → **100 слова** в `assets/db/lives_plus.db`, които
се показват в секцията „СЛОВА ЗА ДЕНЯ" на дневния изглед.

## Редът — ПЪЛЕН, не се съкращава

```bash
cd tools/lives_plus/scripts
python3 01_extract.py              # .epub → work/units/ + отчет   БЕЗ мрежа
python3 02_translate_deepseek.py   # ⚠ ПЛАТЕНАТА стъпка (възобновима)
python3 02b_translate_titles.py    # ⚠ заглавията са ОТДЕЛНИ от абзаците
python3 04_source_links.py         # ⚠ мрежа: адресите в azbyka.ru
python3 05_bible_links.py          # ⚠ библейските препратки → връзки
python3 03_build_db.py             # → assets/db/lives_plus.db
```

⚠ `03_build_db.py` е НАКРАЯ, макар номерът му да е по-малък.

## Находките

⚠⚠ **`01_extract.py` ТРИЕ `work/units/` в началото.** Изхвърлен дял инак
остава като осиротял файл и следващите стъпки честно го намират — влиза в
базата, макар да е бил махнат.

⚠⚠ **В NCX-а етикетът се сдвоява с НЕПОСРЕДСТВЕНО СЛЕДВАЩИЯ `content`.**
navPoint-ите са вложени; „първият src подир `<navPoint`" прескача от бащата в
детето и ИЗЯЖДА заглавието му — така изчезнаха три слова.

⚠⚠ **Свиването по път е СЛЕД филтъра за раздели.** „Часть 2" и първото ѝ
слово сочат един файл (разделът към началото, словото към котва в него).

⚠⚠ **Ключът в `address_manual.csv` е ЗАГЛАВИЕ, не номер.** Номерът идва от
реда в съдържанието и се размества при всяка поправка — веднъж залепи чужди
решения за съседни слова.

⚠⚠ **Затварящата кавичка вътре в CSV поле е капан.** Ред, завършил на `…""`,
изглежда затворен, а `""` е екраниран знак: полето поглъща СЛЕДВАЩИЯ ред.
Затова се брои дали разчетените правила са колкото редовете.

⚠⚠ **Съпоставянето със сайта е ПО ЛИТУРГИЧЕН АДРЕС, не по правопис.** Сайтът
пише „по Пятидесятнице", книгата — „по Святом Духе"; мерена по низове,
приликата е плоска за цяла редица недели и ЕДИН адрес се залепи за ШЕСТ
слова. Правописът решава само вътре в един ден („първо"/„второ" слово).

⚠⚠ **Дългото тире „–" не върви в адреса на препратка.** 142 от 1379 връзки
излизаха неразчетими, при това мълчаливо — адресът изглежда правдоподобен.
Видимият текст остава с дългото тире.

⚠ **Българските Царства са с разместен номер**: „3 Царе" = 3 Царства =
`1King`. Сверено срещу `books.bg_short`, не по памет.

⚠ **Един дубликат, намерен и изхвърлен**: „Поучение о поклонении святым
иконам" стои и в двете книги — един и същ проповед в ДВА превода (първият
абзац съвпада дума по дума, нататък формулировките се разминават). Пази се
`nepe-035`.

## Цената, измерена

`deepseek-v4-pro` дава **~4,7 изходни токена на изходен знак** — над 90% от
тях са „мислене". Мерено на дълъг прозорец: **≈ $8,6 на 1 млн. знака**, тоест
≈ $20 за целия корпус.

⚠ `deepseek-chat` излиза **10 пъти по-евтин** при равностойно качество (с
дописаните правила дори по-добър по преизказно наклонение и кавички), но
потребителят избра Pro (13.09.2026) след сравнение на един и същ текст.

⚠ **Балансът по `/user/balance` ЗАКЪСНЯВА с минути**, а четири дяла са в
полет наведнъж — къс прозорец лъже в двете посоки (мерено: $23,8 и $4,4 за
един и същ пуск).
