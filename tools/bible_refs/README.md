# bible_refs — проверка на библейските препратки

## Какво е това

Не е конвейер, а **инструмент за проверка**. В проекта има ~6400 препратки
към Писанието — в житията и в дванайсетте тома. Този инструмент ги вади
всичките и проверява, че приложението ги разчита **вярно**.

⚠ Не пита „гърми ли“ — това е слаба проверка. За всяка препратка сглобява
**обратно** разчетеното и го сравнява със самата нея. Така тиха грешка в
смисъла („1Sam.1,2:1-21“ значи две неща, не едно) излиза наяве.

## Как се пуска

Два файла, в този ред, **от корена на проекта**:

```bash
python3 tools/bible_refs/extract_refs.py      # → tools/bible_refs/refs.txt
dart run tools/bible_refs/verify_refs.dart
```

Нито един не приема аргументи.

## Кога се пуска

Винаги щом се пипне `lib/bible_ref.dart` — той е чист Dart точно за да може
тази проверка да върви за секунди, без Flutter и без устройство.

## ⚠ Какво да очакваш

- **„Разминавания“ не значи непременно грешка.** Препратка през няколко глави
  („Евр. 7:26-8:2“) законно се разчита на ДВА пасажа, тъй че обратното
  сглобяване не съвпада буквално с входа. Числото е ориентир; гледат се
  редовете „НЕ СЕ РАЗЧИТА“.
- **Три препратки не се разчитат и това е ВЯРНОТО поведение** —
  `Ex.14:15:1-21`, `Lev.4-775-785` (Левит няма 775 глави), `Mt.25-13`. Те са
  повредени в самия източник и празният резултат ги праща навън, вместо да се
  гадае.
