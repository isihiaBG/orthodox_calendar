# Translate_lives — дванайсетте тома „Жития на светиите“

## Какво е това

Най-обемният превод в проекта: дванайсетте тома на свт. Димитрий Ростовски
(руски .epub) → български .epub в `assets/books/`. Оттам ги чете
„Месецослов“.

⚠ **Данните са извън git, скриптовете — вътре.** Без тях томовете не могат да
се произведат наново.

## Пълният ред за ЕДИН том

Всяка стъпка приема `--vol <NN>` (номер на месеца) или `--all`.

```bash
cd tools/Translate_lives/scripts

# 1. Подготовка на изходния том — механична, безплатна
python3 01_merge_notes.py     --vol 09
python3 01b_repair_notes.py   --vol 09
python3 01c_fix_links.py      --vol 09
python3 01d_bible_links.py    --vol 09

# 2. Изваждане на преводимия текст — механична, безплатна
python3 02_extract.py         --vol 09
python3 02b_extract_meta.py   --vol 09
python3 02c_extract_extra.py  --vol 09

# 3. ⚠ ПЛАТЕНАТА стъпка
python3 03_translate_deepseek.py --vol 09 --workers 4

# 4. Сглобяване и изглаждане — механични
python3 04_build_epub.py      --vol 09
python3 05_normalize.py
python3 05b_titles.py
python3 05c_apply_edits.py

# 5. Проверка
python3 06_verify.py --file ../Output/09.epub
```

## Стъпките накратко

| скрипт | какво прави |
|---|---|
| `01_merge_notes` | стотиците едноредови файлове с бележки → един `notes.xhtml` |
| `01b_repair_notes` | връща бележки, повредени при нарязването на общата книга |
| `01c_fix_links` | мъртвите кръстосани препратки → работещи (само в същия том) |
| `01d_bible_links` | библейските препратки → **български** текст |
| `02_extract` | преводимият текст, групиран по светия; **моделът не вижда markup** |
| `02b_extract_meta` | надписите на съдържанието и името на книгата (те са в `toc.ncx`/`content.opf`) |
| `02c_extract_extra` | текстът извън разпознаваните блокове (заглавната страница) |
| `03_translate_deepseek` | ⚠ превежда |
| `04_build_epub` | връща превода по местата му и запушалките → тагове |
| `05_normalize` | изравнява повтарящи се низове („Иулиан“/„Юлиан“) |
| `05b_titles` | заглавията на 12-те тома по единен образец |
| `05c_apply_edits` | точкови поправки, които трябва да преживеят прегенериране |
| `06_verify` | проверките |

## Полезни аргументи

```bash
python3 03_translate_deepseek.py --vol 09 --limit 3      # пилот
python3 03_translate_deepseek.py --vol 09 --group 12     # само една група
python3 03_translate_deepseek.py --vol 09 --redo         # наново
python3 02_extract.py --vol 09 --stats                   # само статистика
python3 01c_fix_links.py --all --dry-run
```

⚠ **`06_verify.py` НЕ приема `--vol`; иска `--file <път>`.**

## ⚠ Предупреждения

- ⚠⚠ **Поправки в превода се нанасят В ИЗВОРА** (`work/<том>/translated/*.json`),
  не в готовия .epub — инак се губят при следващото сглобяване.
- ⚠⚠ **РЕДЪТ НА `renumber_notes()` (вътре в `04_build_epub.py`) Е РЕШАВАЩ.**
  Тя тръгва СЛЕД цикъла с превода. Пусната по-рано, оправя `href`-а, а
  `rebuild_file()` веднага след това залепва видимия номер обратно от превода
  — линкът работи, а в текста пише старото число. **Нито една автоматична
  проверка не го хвана**; намери го потребителят във външен четец.
- ⚠ **Сверявай ВИДИМИЯ текст, не само структурата и линковете.** `06_verify.py`
  следи дали препратките сочат някъде, не дали номерът съвпада с целта.
- **Шрифтът се вгражда подрязан** до знаците на тома (61 KB вместо 822) и
  `OFL-CharisSIL.txt` пътува вътре в книгата — OFL го изисква.
- **Класът на молитвите е в отделен атрибут** (`data-prayer`), а НЕ в
  `class="paragraph …"`: проверките броят абзаците по буквалното
  `class="paragraph"`.
