# reference_gen — секцията „Справочник“

## Какво е това

47 руски текста с богослужебни указания, преведени на български. Пълнят
`assets/db/reference.db` — базата на секцията **„Справочник“**.

⚠⚠ **Истинският конвейер е в подпапката `Translate/`.** В корена стои само
`build.py`, който е **НАДЖИВЯН и опасен** — виж предупреждението долу.

## Как се пуска

```bash
cd tools/reference_gen/Translate/scripts

python3 01_extract.py            # input/*.txt → work/units/   (безплатно)
python3 02_translate_deepseek.py # ⚠ ЕДИНСТВЕНАТА платена стъпка
python3 03_build_db.py           # → assets/db/reference.db
```

Целият превод струваше около **13 цента**.

## ⚠⚠ НЕ ПУСКАЙ `build.py`

`tools/reference_gen/build.py` създава базата с **ПРИМЕРНО** съдържание.
Пуснат, той **ЗАТРИВА** истинските текстове. Държи се само като напомняне за
първоначалната структура. Ако не ти трябва за справка — по-добре го изтрий.

## ⚠ Предупреждения

- **Поправки по превода се нанасят в `work/translated/*.json`** (полетата
  `title_bg`/`units_bg`), после се пуска `03_build_db.py`. Поправка направо в
  базата се губи при следващото сглобяване.
- **Съкращенията (група 5-01) НЕ са преведени** — руските нямат съответствие
  едно към едно и се чакат на ръка.
- **Знаците на Типикона** са запушалки `⟦znak1⟧` в JSON-а, които
  `03_build_db.py` превръща в тагове **след** екранирането. ⚠ Тагът се затваря
  изрично — самозатварящ се `<znak/>` поглъща остатъка от абзаца.
- **Живи променливи**: `⟦пост⟧` се заменя при всяко отваряне в приложението
  („започналия вече Богородичен пост“ / „предстоящия Велик пост“). Логиката е
  в `lib/reference_text.dart`.
- ⚠ **Дължим цитиране.** Текстовете идват от руското приложение на
  **Oleksandr Kotyuk**. Виж бележката в CLAUDE.md.
