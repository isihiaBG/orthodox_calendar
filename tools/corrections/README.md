# corrections — масови поправки в превода

## Какво е това

Преводът е машинен и от време на време изплува дума, сгрешена **навсякъде
наведнъж** — „служене“ вместо „служение“ се оказа на 287 места. Поправянето ѝ
на ръка значи обиколка на пет конвейера и две бази. Тук стои **един списък**
и **един скрипт**, които го правят наведнъж и може да се пускат колкото пъти
трябва.

## Файловете

| файл | какво е |
|---|---|
| `replacements.tsv` | **списъкът** — по една двойка на ред, разделени с табулация |
| `apply.py` | нанася; знае само какво да мени |
| `corpora.py` | знае **къде живее преводът**; единственото място с тези пътища |
| `backups/` | по едно `.tar.gz` на пускане — единственото връщане назад |

## Как се пуска

Всичко от корена на проекта.

```bash
# 1. Кои форми на думата реално ги има в текстовете
python3 tools/corrections/apply.py --forms служен

# 2. Какво БИ сменил — нищо не се пипа
python3 tools/corrections/apply.py --dry-run

# 3. Нанася
python3 tools/corrections/apply.py

# по избор: само в един корпус
python3 tools/corrections/apply.py --only optina teofan
```

**Аргументите:**

- `--forms <стъбло>` — показва истинските словоформи в текстовете. Ползвай го,
  преди да пишеш ред в списъка: на око се пропускат точно редките
  („страстотърпецо“, „нарочитем“).
- `--dry-run` — показва, без да пипа.
- `--only <корпус> …` — ограничава до избрани корпуси.
- `--survey` — преглед на срещанията.
- `--limit N` — само първите N.

Накрая скриптът **сам изписва кои конвейери трябва да се пуснат наново**, за
да стигне поправката до готовите изделия.

## ⚠ Предупреждения

- **Пипат се ИЗВОРИТЕ, не изделията.** Поправка направо в базата или в .epub-а
  се губи при следващото сглобяване. Изключение е само `lives.db` — тя се
  кърпи и на място, защото пътят до нея минава през скриптове, които теглят
  наново от azbyka.ru.
- ⚠⚠ **Архивчето в `backups/` е ЕДИНСТВЕНОТО връщане назад** — нито един
  преводен извор не е в git (тежест и чужди права). Назад:
  ```bash
  tar xzf tools/corrections/backups/<име>.tar.gz -C .
  ```
- **Всяка форма иска свой ред. Скриптът НЕ скланя.**
- **Гъвкава е само ПЪРВАТА буква.** Пълно нечувствително сравнение би свалило
  вътрешните главни: „по завръщането **Си**“ (за Христа) щеше да се обезличи.
- **Внимавай със замените по част от думата.** Веднъж „низвергнат“ стана
  „ннизвергнат“, защото съдържа „изверг“. Пиши от най-дългата форма към
  най-късата.
- **Латинско „a“ насред кирилска дума** се отхвърля при зареждане — изглежда
  еднакво, а никога не съвпада.
- **Скриптът отказва верижни двойки** (дясна страна, която пак се търси
  отляво) — инак всяко пускане би менило по два пъти.
