# Сверка с календара на pravoslavieto.com (27.09.2026)

```bash
cd tools/calendar_compare
python3 01_parse.py      # pravoslavieto_calendar.htm → work/theirs.json (365 дни, 1003 записа)
python3 02_compare.py    # срещу assets/db/calendar_new.db → work/report.md
```

Изворът е https://pravoslavieto.com/1/calendar.htm (свален 27.09.2026). Той е
календар по **нов стил** за 2013/2014 г., тъй че датата там Е църковната и се
сравнява с нашите неподвижни памети по ММ-ДД. Търсят се само **НАШИ**
пропуски — техните не ни интересуват (задание на потребителя).

## Капаните

- ⚠ **HTML коментарите на сайта носят редакторски бележки** („2013 старост:
  …“, „OBS † ок. 815“). Махат се ПРЕДИ разчитането, иначе влизат като записи.
- ⚠ Първата половина на страницата е кратък списък „ЦЪРКОВНИ ПРАЗНИЦИ“ —
  истинският календар е под `<h2>Месец</h2>`, всеки ден е `<p>N …</p>`,
  понякога с `<a name="ММ.ДД">` пред числото.
- ⚠ **Съвпадението е ПО ДУМИ и се лъже в двете посоки.** Изписванията се
  разминават („Раиса“/„Ираида“, „Иаков“/„Яков“, „Макрела“/„Маркела“, „чудото
  в Колоса“/„в Хони“, „Николай Велимирович“/„свт. Николай, еп. Жички“), тъй
  че „не се намира“ НЕ значи „липсва“. Всеки кандидат се сверява на ръка в
  семето с няколко изписвания. Отчетът е списък за преглед, не присъда.
- ⚠ Голяма част от „друга дата“ са **различни традиции**, не грешки: семето
  следва руския месецослов, сайтът — гръцката/българската практика
  (вмч. Меркурий 24 срещу 25.XI, прп. Никодим Светогорец 14 срещу 1.VII,
  свт. Флавиан 18 срещу 16.II). Такива не се „поправят“.
