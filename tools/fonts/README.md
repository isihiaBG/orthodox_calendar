# fonts — кръпки по шрифтовете

## Какво е това

Един-единствен скрипт. Заглавията на четивата се пишат с **Tamburin
Modern**, но той покрива само 229 знака и в него **липсват „ѝ“ и „Ѝ“** —
а те се срещат в имена на светии („Прмц. Евдокѝя (Ѝя)“, „…и синовете ѝ“).
Без тях Flutter вземаше системния шрифт и една буква изглеждаше от друг
текст.

Скриптът ги **сглобява геометрично** от знаци, които шрифтът вече има:

```
ѝ = и + grave, центрирано отгоре
Ѝ = И + grave, центрирано отгоре, по-нависоко
```

## Как се пуска

```bash
python3 tools/fonts/patch_tamburin_izh.py --dry-run   # само показва
python3 tools/fonts/patch_tamburin_izh.py
```

**Идемпотентен е** — пусни го наново, ако шрифтът някога се замени с нова
версия на Tamburin.

## ⚠ Предупреждения

- ⚠⚠ **Оставя `.bak-…` до самия файл — махни го на ръка след проверка.**
  `assets/` влиза цялата в APK-то, тъй че копието пътува при потребителите.
  Оригиналът и без това е в git историята.
- **U+0301 (комбиниращото ударение в „Тео́фил“) остава на Charis SIL.** В
  Tamburin няма нищо, годно за акутно ударение. Огледално обръщане на `grave`
  беше обмислено и **отхвърлено**: при калиграфски шрифт обърнатият диагонал
  не изглежда естествено, а един случай не оправдава риска.
- **Преди да смениш шрифт, провери покритието срещу базите, не на око.**
  PT Serif изглеждаше отличен избор, а му липсват 94 знака, които данните
  реално ползват — включително „ѝ“ (в 310 от 1033 жития).
- **Pillow не търси резервен шрифт, Flutter търси.** Квадратчетата в сравнителни
  картинки с PIL са по-черна картина от действителната. Меродавно е
  устройството.
