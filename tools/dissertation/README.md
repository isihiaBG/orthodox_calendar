# dissertation — изворен материал, не конвейер

## Какво е това

**Няма скриптове.** Папката пази един документ:

```
Дисертация - Пламен Михайлов.pdf
```

Използва се като **справочен извор** за българските светии — оттам излезе
списъкът с деветте светии, които изобщо нямат ред в календара (Ефрем патр.
Сръбски, Киприан митр. Киевски, Сергий Къпински, Никодим Албански, Константин
Софийски, Дионисий Костурски, Никита Серски, Акакий Серски, Аврамий
Български).

## ⚠ Предупреждения

- **Чужд труд.** Папката е в `.gitignore` и файлът не се разпространява.
  Цитирай автора, ако от него влезе съдържание в приложението.
- **Нищо не се пуска.** Ако търсиш конвейерите за български жития, те са в
  `tools/lives_bg/`, `tools/lives_mitropolia/` и `tools/lives_extra/`.
