# lives_mitropolia — жития на български светии от Софийска митрополия

## Какво е това

**Втори извор** за жития на български светии, след `tools/lives_bg/`
(pravoslavieto.com). Поводът: там ги няма св. цар Тервел, св. Райко-Йоан
Шуменски и още десетина, а сайтът на **Софийска света митрополия** ги има в
поредицата „Кръстният подвиг на българските светии“.

## Пълният ред

```bash
cd tools/lives_mitropolia/scripts

python3 01_index.py      # ⚠ мрежа: указателят на поредицата → work/index.json
python3 02_match.py      # кои ни липсват          → work/plan.json
python3 03_apply.py      # ⚠ мрежа: тегли, разчита и внася → assets/db/lives.db
```

## Стъпките една по една

**01_index.py** — обхожда категорията и прави `{адрес: заглавие}`. Страниците
се пазят в `cache/` и не се теглят повторно.
```bash
python3 01_index.py
python3 01_index.py --force        # нов обход, въпреки кеша
python3 01_index.py --pages 5      # ограничава броя страници
```

**02_match.py** — оставя само онези, за които светията **съществува в
календара**, но няма житие (или има твърде късо).
```bash
python3 02_match.py
python3 02_match.py --all          # всички намерени, не само липсващите
```

**03_apply.py** — тегли по плана, разчита и внася.
```bash
python3 03_apply.py --dry-run
python3 03_apply.py --only sv-tervel
python3 03_apply.py
```

## ⚠ Предупреждения

- ⚠⚠ **ЗАСИЧАНЕТО ПО ИМЕ Е НЕНАДЕЖДНО и не му се вярва.** Тук то разменяше
  двамата Йоановци (Български ↔ Търновски), лепеше цар Петър за списък
  мъченици с друг Петър, а Йоан Кукузел — за Йоан Български. Затова
  **всичките 11 връзки са РЪЧНИ**, в `input/manual_map.csv`, всяка с бележка
  защо.
- **Скриптът е идемпотентен** — пази какво е имало преди него и строи от
  запомненото. ⚠ Изтриеш ли този запис, повторното пускане **удвоява**
  текста.
- **Прави резервно копие в `backups/`** преди да пипне базата. ⚠ Базите не са
  в git — това копие е единственото връщане назад.
- **Списъкът с титли се свива като имената.** Веднъж филтърът не съвпадаше,
  защото в списъка стоеше „български“, а свиването маха „ъ“ — и титлите
  участваха в сравнението, тъй че двама различни българи си приличаха само
  защото са българи.
